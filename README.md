## Confirmación de puesta en funcionamiento

El proyecto fue levantado localmente utilizando Docker Compose y PostgreSQL. Se creó y cargó la base de datos `dwsismos_bd` y se realizaron consultas directamente sobre la base de datos para verificar los registros cargados.

La documentación del procedimiento se encuentra en:

`Proyecto asignado/levantamiento.md`

Las capturas del arranque, los contenedores y las consultas a la base de datos se encuentran en:

`Proyecto asignado/Evidencias/`

## Estructura de la entrega

- `Proyecto propio/`: requisitos ampliados y modelos EER del proyecto MusicStore.
- `Proyecto asignado/`: levantamiento, modelo EER, correspondencia con el esquema y evidencias del proyecto DWSismos.

- `propuestas/`: propuestas de mejora de ambos integrantes.
- `exposicion/`: presentación final de la práctica.
